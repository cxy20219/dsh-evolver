# dsh-evolver

自我演化控制台：一个插件、一个侧边栏入口、一套统一的卡片知识库。
**只有三样东西进入 Agent 的每次上下文**：2 KB 的标签树（含标签说明与沉淀纪律）、灵魂、主动性协议。具体卡片不注入，全部由检索按需取。

```
~/.dsh/evolver/                  ← 唯一数据目录（迁移 / 云备份的单位）
  knowledge/
    cards/cards.jsonl            ← 卡片日志：追加写，最后一条同 id 记录生效
    resources/<card-id>/         ← 卡片附件：长文、脚本、模板
  sight/
    soul.md                      ← 灵魂（注入）
    sessions.json                ← 闲时整理的会话游标
  preferences/AGENTS.md          ← 全局偏好（链到 ~/.dsh/AGENTS.md）
  models/<模型>/                 ← 本地 embedding 权重（随备份/导出）
```

## 卡片模型

一张卡片就是一行 JSON，**没有分类字段，也没有标题**；分类全部由层级标签表达：

卡片存储只保留必要字段：

```json
{
  "id": "card-01M72KRG4VQEQQ25BM3DTHB97X",
  "body": "[沉淀纪律与脚本优先](knowledge/resources/<card-id>/sinking.md)：用途、入口命令、输入输出、关联流程...",
  "tags": ["践行/工作流"],
  "links": ["card-01..."],
  "updated": "2026-11-10T13:40:16.269Z",
  "verified": "2026-11-10"
}
```

- **id**：ULID；`created` 从 id 前 10 位派生，不存储。
- **body**：正文；`label` 从正文首行或首行附件链接标题派生，不存储。
- **tags**：唯一的分类入口。**顶层只允许六个枝干**：
  - `#践行` 落地与持续行动，偏个人执行；子标签如 `践行/经验`、`践行/工作流`、`践行/工具`
  - `#见闻` 外部输入与阅历积累；子标签如 `见闻/事实`、`见闻/网络`、`见闻/工具怪癖`
  - `#即兴` 主动应变与灵活创造；新卡默认入口
  - `#复盘` 事后反思与经验提炼；子标签如 `复盘/经验`、`复盘/纠正`、`复盘/踩坑`
  - `#觉察` 对内关注情绪、模式与盲区；子标签如 `觉察/偏好`、`觉察/模式`、`觉察/盲区`
  - `#试错` 低成本探索与迭代；子标签如 `试错/实验`、`试错/踩坑`
  归档写成 `<枝干>/归档`，例如 `践行/归档`；不要创建第七个顶层标签。
- **links**：可选；空数组不写。反链实时计算。
- **updated**：最后写入时间。
- **verified**：可选；最后复查日期。
- 附件不写进卡片 JSON：文件在 `knowledge/resources/<card-id>/`，正文引用即索引。

标签是唯一的分类事实：没有单独的 `type`、`shape`、`status`、`category`、`topic` 或 `scope` 字段。
也没有 `label`、`summary`、`source`、`created`、`resources` 元数据。
父标签自动包含子标签，所以 `#践行` 能搜到 `#践行/工作流`，`#觉察/偏好` 能继续向下生长。

### 附件引用

带附件的卡片，正文必须写一行引用，不能只把文件塞进附件：

```text
[脚本标题](knowledge/resources/<card-id>/<文件名>)：用途：...；入口命令：...；输入：...；输出：...；关联流程：...
```

- 路径相对**数据目录**，不是相对工作区；`card_read` 会同时返回附件的绝对 `path` 和 `executable`，执行时用绝对路径。
- agent 写新卡时还不知道 card id，可以在 `card_write` 的 body 里写 `{{resource}}` 占位符；写入时替换成最终相对路径。
- 有 `resourceName` 就必须同时有 `resourceContent`（完整文件内容），正文只放引用与说明；缺引用会被拒绝写入。
- 脚本、shebang、ELF/PE/Mach-O 等原生可执行附件自动 `0700`；普通文档保持 `0600`。
- 面板添加附件时会自动补一行通用引用，之后可编辑正文补全入口命令和输入输出。

### 注入与检索

| 消费者 | 内容 |
| --- | --- |
| 每次请求的 system prompt | 2 KB 预算：沉淀纪律 + 标签树 + 已知标签说明（如 `#践行/工作流 — 可重复执行的流程…`）。不出现任何具体卡片的 label、id 或正文 |
| Agent 的 `card_query` / `card_read` | 全部卡片（BM25 + 向量 + 生命周期 + 标签过滤）；具体内容按需检索 |
| 双链 | 卡片 id 链接与反链，配合标签树继续跳转 |

写卡片的顺序建议：新卡默认 `#即兴` → 判断后选一个枝干，用 `card_promote` 或面板「整理」移入 `#践行` / `#见闻` / `#复盘` / `#觉察` / `#试错`。

## 注入的三个来源

| 部分 | 内容 | 载体 | 预算 |
| --- | --- | --- | --- |
| 标签树 | 纪律 + 标签树 + 标签说明 | `systemPrompt.section`（order 900） | 2 KB |
| 灵魂 | `sight/soul.md` | `systemPrompt.section`（order 910） | 1 KB |
| 主动性 | 何时召回、何时沉淀、收尾给下一步 | `systemPrompt.section`（order 920） | 744 B |
| 偏好 | `preferences/AGENTS.md` | DSH 的 `dsh-agent-instructions` | 用户自控 |

任何卡片都**不自动注入**：需要时由 `card_query` 或面板按需取。写入超限不会悄悄变大：
灵魂 16 KB、偏好 64 KB、单条 #即兴 卡 4000 字、卡片正文按设置上限。

## 工具

| 工具 | 作用 |
| --- | --- |
| `card_query` | 按关键词/层级标签检索全部卡片；`archivedOnly` 只看归档（Host 侧执行，不受会话权限预设影响） |
| `card_read` | 读一张卡，含正文、链接和资源附件；附件带绝对路径与可执行标记 |
| `card_write` | 写入/更新卡片；分类由 tags 表达。带附件时必须 `resourceName` + `resourceContent`，且 body 含 `[标题]({{resource}})：用途、入口命令、输入输出、关联流程` |
| `card_index` | 完整标签树 + 标签说明（不含卡片 label/id/正文） |
| `card_promote` | 把 #即兴 卡片移入六大枝干之一（tags 指定目标） |
| `card_archive` | 加 `<枝干>/归档`，保留记录和资源 |
| `card_remove` | 永久删除卡片及资源 |
| `evolve_review` | 一次拿到卡片库盘点与可执行 hints |
| `session_digest` | 读取没整理过的会话摘录（手动整理用） |

没有 `practice_*` / `memory_*` 兼容别名，也没有旧 slug 解析：工具、面板和导入导出
只认 `card_` 开头的 ULID。

## 沉淀纪律（已内化）

- **触发**：完成多步工具调用（≥3 步）后，出现了已验证且可复用的判断、流程、验证方法或工具。
- **边界**：只写能减少未来误判、重复劳动或验证成本的内容；不写流水账、一次性命令、猜测、
  废弃方案、密钥、令牌、完整日志和对话转录。密钥在写入前会被识别并拒绝。
- **查重**：写前 `card_query`，能更新已有卡片就不新建。
- **脚本优先**：稳定流程、重复转换、结构化输出解析、需要可重复验证时，用 `card_write`
  并把 `#践行/工具` 作为标签写成可运行脚本，而不是只写文档。
- **闭环**：链接只能是卡片 id；写永久卡时确认 `verified` 日期，长期未验证的结论要复查。

纪律文本自己也算在 2 KB 预算里（约 430 字节），细节留在种子卡里，需要时 `card_read`。

## 主动性

注入的 `[主动性]` 段落规定触发点，不靠临场发挥：

- 任务前有明确相关词，先 `card_query`；
- 任务后可复用的写 `card_write`（先查重），临时结论也写 `card_write`，先放 `#即兴`；
- 收尾给一条具体、可执行的下一步（命令 / 文件 / 验证方式）；
- 同一流程第二次出现，提议整理进六大枝干或脚本化；
- 盘点用 `evolve_review`，有结构问题或久未验证时用一句话提醒；
- 不确定时先做可逆部分，只问那个会改变结果的决策。

`evolve_review` 返回有界摘要：六个枝干数量、`#即兴` 待整理项、带 `verified` 的久未复查卡和 `hints`；
没有高信号时会明说“不用为了主动而主动”。

## 会话整理（闲时自动）

默认开启：宿主连续 15 分钟没有会话活动、且存在没整理过的会话时，插件直接调用当前默认
模型做一次受限提取，把值得留下的偏好/纠正/结论写成 #即兴 卡。

- **不创建会话、不给工具**：纯文本模型调用，Agent 不会在后台读文件、跑命令或写卡片。
- **只读用户与助手的文本**：工具输出、系统提示、推理内容都不进摘录；单条/单会话/整批都有
  长度上限。摘录里的常见密钥会被抹掉，保存前还会再查一次。
- **游标**：`sight/sessions.json` 记录每个会话处理到的 seq；只读新增部分，最多一次处理
  10 个会话、保存 6 张 #即兴 卡。全部保存成功后才推进游标，失败 6 小时后重试。
- **成本**：每次闲时触发一次模型调用，输出上限 2500 token；没有待整理会话时不会调用。
- 面板「卡片」页显示待整理/已处理数量、上次完成时间；「立即整理」立刻跑一次。
- 只在 App 运行期间触发；模型未选择或宿主不提供会话读取时显示不可用。

## 面板

概览（笔记/标签/天统计、最近 30 天创建热力图、可折叠标签树、注入预览、预算、插件版本）/ **卡片**（层级标签树、全部/践行/见闻/即兴/复盘/觉察/试错/归档、
搜索、无标题编辑、整理、归档、删除、附件、双链与反链）/ **灵魂** / 偏好 / 建议 / 设置。

左侧标签树每一层都可以展开/收起，子标签的子标签同样递归折叠；点击标签名用于过滤。

卡片页顶部的「闲时自动整理」可以开关、调空闲分钟数、立即运行。

## 设置页

「设置」页分四个子标签：**数据目录**、**导入 / 导出**、**云端备份**、**向量模型**。

### 数据目录

- 默认 `~/.dsh/evolver`；设置里指定的目录优先于组合配置里的 `dataDir`。
- **卡片正文上限**：200–4000 字，默认 1000；改完立即作用于新写入的卡片和检索文本。
- 数据目录和导出目录都能用「浏览…」调起系统文件夹选择，也可以手动粘贴绝对路径。
- 迁移 = 先把当前目录完整复制到新路径，复制成功、设置写盘之后才切换；旧目录原样保留，
  可回滚；目标目录非空时必须显式勾选覆盖。
- 设置里记录的目录如果不存在（例如外置盘没挂载），本次启动退回默认目录并在设置页给出警告。
- 导入 / 导出用 `.tar.gz`：导出目录 + 文件名（默认 `dsh-evolver-<时间戳>.tar.gz`）；
  导入可直接选 `.tar.gz` / `.tgz` / `.tar`。包内只允许写入 `knowledge/`、`sight/`、
  `preferences/`、`models/`，路径穿越条目会被拒绝。

### 云端备份（阿里云 OSS）

- 整个数据目录打成一个 **tar**（标准 ustar，`tar -xf` 直接可解）上传；对象名
  `‹prefix›/backup-‹YYYYMMDDTHHmmssSSSZ›.tar`，按时间可排序；文件权限随 tar 保留。
- 「云端保留份数」1–60；「备份间隔」5–10080 分钟；重启后补一次。
- 密钥只写进本机 `~/.dsh/evolver.config.json`（0600），不回传浏览器、不写日志，
  也不会被打进备份（备份只包含数据目录）。
- 使用 OSS V1 签名；endpoint 主机名走虚拟主机风格，`http(s)://` 完整地址走路径风格
  （自建网关 / MinIO）。V4 签名账号不支持。
- 恢复：下载 `backup-*.tar`，在设置页「从压缩包导入」直接选；也可 `tar -xf` 手动查看，
  或停掉宿主后替换数据目录。

### 向量模型（embedding）

卡片默认用**本地哈希**向量：零配置、离线，但只比较词面。设置页「向量模型」
可以换成本地 ONNX 模型或任意 OpenAI 兼容 HTTP 服务；切换后在后台重建全部向量，期间
召回自动退回关键词。

| 模型 | 语言 | 维度 | 量化权重 | 说明 |
| --- | --- | --- | --- | --- |
| `multilingual-e5-small` | 中文 + 英文 + 多语 | 384 | ~135 MB | 默认推荐，中英均衡 |
| `bge-small-zh-v1.5` | 中文为主 | 512 | ~25 MB | 体积最小，中文优先 |
| `bge-m3` | 中英 + 多语 | 1024 | ~587 MB | 质量最高，加载慢 |

- 权重在数据目录的 `models/<模型>/`，随备份、导入、导出一起走。
- 下载源默认 `https://hf-mirror.com`，可改成 `https://huggingface.co`。
- 本地模型需要运行时（transformers.js + ONNX runtime），插件不打包它：
  `npm install --prefix "$HOME/.dsh/embedding-runtime" @huggingface/transformers`
  （约 300 MB）。运行时缺失时自动退回本地哈希，不会阻断启动。
- HTTP 模式填 OpenAI 兼容 `/v1/embeddings` 地址，例如 Ollama：
  `http://127.0.0.1:11434/v1` + 模型 `bge-m3` / `nomic-embed-text`；API Key 只写不读。
- 「测试后端」会真的嵌入两段中英文样本，返回实际后端、维度与耗时；配置不可用时明确提示
  已退回哈希。换后端/模型会分批重算全部向量，全部成功才整体替换；失败保留旧向量。

### 设置文件

`~/.dsh/evolver.config.json`（0600）保存数据目录、卡片正文上限、备份配置、向量配置、
密钥和上次备份状态。它不在数据目录里：移动数据目录不会丢设置，云备份也不会带上密钥。

## 无旧版兼容

5.0 没有旧版兼容：没有 `practice/` / `sight/memory/` 导入，没有旧 HTTP 接口，
没有旧 slug、旧向量格式或旧权重目录迁移，也没有旧分类字段的读取分支。唯一的输入是
`knowledge/` 卡片日志；新数据目录只写卡片和资源。2.x 的卡片请先用 2.x 版本导出或迁移，再升级。

## 文件与链接的边界

- 卡片附件写在 `knowledge/resources/<card-id>/`，文件名压成单段，拒绝符号链接；
  单文件 10 MB 上限，读取超过 512 KB 的文本只返回截断内容。
- `~/.dsh/AGENTS.md` 只在「不存在」或「是普通文件」时自动接管（原文件先备份为
  `preferences/AGENTS.md.imported`）；已被别的工具链接时不抢，面板里点「接管」才替换。
- `dataDir` 必须是绝对路径。

## 安装

详细步骤（安装与卸载）见 [INSTALL.md](INSTALL.md)。

```bash
# 从目录安装（git clone 后，或解压压缩包后）
dsh plugin --profile web add /path/to/dsh-evolver

# 确认行状态
dsh plugin --profile web why dsh-evolver
```

插件自带 `cordis.patch.yml`：插入自己的行，并把 web 组合默认关闭的
`agent-instructions` 打开，让全局偏好真正进入 Agent 的上下文。

首次启动会创建 `~/.dsh/evolver/` 骨架、种下三张践行/复盘卡，并把 `~/.dsh/AGENTS.md` 链到
`preferences/AGENTS.md`（原本是真实文件时先备份为 `AGENTS.md.imported`）。
